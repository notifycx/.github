# Notify (`notifycx`)

Official open-source clients for **[Notify](https://notify.cx)** — a deliberately minimal transactional email API.

## Primary repository

**[notifycx/notifycx](https://github.com/notifycx/notifycx)** — Node/TypeScript SDK (`notifycx`) and official MCP (`notifycx-mcp`).

## What this org is

- Public home for Notify’s **SDK** and **MCP**
- Thin `fetch` examples that call `https://notify.cx`

## What this org is not

- Not the Notify product server (SES, billing, dashboard stay private)
- Not a second email API implementation
